## 四、处理链对比

### Stall Breaking

```
基准版:  LLM输出 → extract_stalled_message → format_request_message → 执行
扩展版:  LLM输出 → clean_llm_response → extract_stalled_message → format_request_message → 验证 → [反馈重试] → 执行/丢弃
```

### Seed Enrichment

```
基准版:  LLM输出 → unescape → 与原seed比较 → format_request_message → 写入
扩展版:  LLM输出 → clean_llm_response → unescape → 与原seed比较 → format_request_message → 验证 → [反馈重试] → 写入/丢弃
```

## 七、实验注意事项

1. **扩展版 V0 ≠ 基准版**：V0 仍有 `clean_llm_response()`、更大的 Token 预算、`CHATTING_THRESHOLD=512`
2. **V1/V2 自动启用 feedback**：`afl_llm_validation=1` 时 `afl_llm_feedback` 自动为 1
3. **`CHATTING_THRESHOLD` 差异 8 倍**：扩展版 LLM 参与度远高于基准版
4. **`clean_llm_response()` 可能是最大贡献**：基准版无输出清洗，扩展版有
