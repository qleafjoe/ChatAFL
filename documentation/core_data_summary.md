## 3. 核心发现

1. **TR2 (PromptClean) 效果最佳**：状态节点14，转换150.5，最接近TR1基线（-1.4%/-5.9%）
2. **TR4 路径多样性最高**：1,098条路径，挂起仅32个，但协议覆盖下降19%/44%
3. **Xiaomi模型在复杂协议上表现更优**：FTP节点+25%，转换+53.4%（对比MiniMax）
4. **Xiaomi-RTSP接近TR1基线**：节点仅差1.4%，转换差11.9%
