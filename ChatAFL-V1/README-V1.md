# ChatAFL-V1：Format-Only Validation + Feedback Retry

## 定位

仅启用格式级验证 + 反馈重试。通过 `env.sh` 运行时切换，薄覆盖层架构。

## 运行时配置（env.sh）

```bash
AFL_LLM_VALIDATION=1         # 验证启用
AFL_LLM_VALIDATION_STRICT=0  # 仅格式验证（无语法/上下文）
AFL_LLM_POST_GAIN=0          # 执行后增益归因禁用
AFL_LLM_SKIP_STARTUP=0       # 不跳过启动时 LLM 语法提取
# AFL_LLM_FEEDBACK 未显式设置 → 代码默认值为 1（启用）
```

## 构建模型

**薄覆盖层**。`build_targets.sh` 执行两步 rsync：
1. 将 `ChatAFL/` 基线完整源码复制到目标目录
2. 将 `ChatAFL-V1/` 中的 `afl-fuzz.c` 和 `env.sh` 覆盖到目标目录

V1 目录仅包含 2 个文件：`afl-fuzz.c` 和 `env.sh`。其余所有源文件（`chat-llm.c`、`aflnet.c`、`llm-validator.c` 等）从基线继承。

## 核心特征

- 验证模式为 **Format-Only**：仅检查 LLM 输出的基本格式（如是否为合法 RTSP/FTP 消息格式），不检查语法完整性和协议上下文一致性
- 反馈重试**启用**（代码默认值）：格式验证失败时，将错误信息反馈给 LLM 并重试
- 执行后增益归因**禁用**：不记录 LLM 生成输入是否产生新覆盖
- 种子去重、LLM 种子优先级、动态变异权重均**启用**（从基线继承）

## 验证级别说明

| 验证级别 | V1 状态 | 说明 |
|---------|---------|------|
| Format（格式） | **ON** | 检查消息基本格式合法性 |
| Grammar（语法） | OFF | 不检查协议语法完整性 |
| Context（上下文） | OFF | 不检查协议状态一致性 |

## 与 V0 的关键差异

| 特性 | V0 | V1 |
|------|----|----|
| 构建模型 | 独立完整源码 | 薄覆盖层 |
| 验证 | 完全禁用 | 格式级验证 |
| 反馈重试 | 禁用 | 启用（默认） |
| 种子去重 | 无 | 有（继承） |
| LLM 种子优先级 | 无 | 有（继承） |
| 动态变异权重 | 无 | 有（继承） |
| 状态转换图 | 无 | 有（继承） |
| llm-validator.c/h | 不存在 | 继承自基线 |

## 与 V2 的关键差异

V1 和 V2 共享**完全相同的 `afl-fuzz.c`**（MD5 一致），唯一区别在 `env.sh`：

| 配置 | V1 | V2 |
|------|----|----|
| `AFL_LLM_VALIDATION_STRICT` | **0**（仅格式） | **1**（语法+上下文） |
| `AFL_LLM_POST_GAIN` | 0 | 0 |

## 行为总结

V1 是验证框架的**最低配置**：仅做格式检查，不做语法和上下文验证。反馈重试启用，但重试的反馈信息仅包含格式错误。消融实验中用于隔离"格式级验证"相比"无验证"（V0）和"完整验证"（V2）的贡献。
